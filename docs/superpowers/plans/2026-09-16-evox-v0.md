# EvoX v0 Active Lineage Modes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and falsify a minimal evolutionary system that discovers behaviorally distinct executable-program modes, actively probes which mode generated a hidden task, and tests whether the identified mode is reusable on a related task.

**Architecture:** A tiny safe expression-tree GP evolves programs on an intentionally ambiguous visible dataset. Viable programs are represented only by their counterfactual outputs, decomposed with SVD, and clustered into behavioral modes; a Bayesian information-gain policy chooses probes, then identified-mode descendants compete with wrong-mode and fresh-restart searches on a follow-up task.

**Tech Stack:** Python 3.11+, NumPy, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-16-evox-v0-design.md`

## Global Constraints

- Python 3.11+.
- Runtime dependency: NumPy only.
- Test dependency: pytest.
- No `eval`, dynamic code execution, network access, or external benchmark dependency in v0.
- All canonical randomness is seed-controlled.
- Canonical experiment must run comfortably on GitHub Actions CPU.
- Mode extraction and active probing must not consume syntax-family labels or ancestry labels.
